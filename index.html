01 About

I'm a cloud engineer and trainer based in Jakarta, currently supporting Huawei Cloud Indonesia as a Solution Architect Engineer Assistant — driving pre-sales solutioning, customer workshops, and technical presentations from design through commercial close.

My path into cloud started from 8+ years managing physical servers, virtualization, networking, storage, and backup across Windows and Linux environments. That hands-on infrastructure background is what I bring into every cloud conversation — I don't just recommend architectures, I understand what it takes to run them.

I've trained AWS technologies for partners and clients across APAC, and I've been recognized as an Alibaba Cloud Most Valuable Professional (MVP) since 2019 for my contributions to the cloud community.
